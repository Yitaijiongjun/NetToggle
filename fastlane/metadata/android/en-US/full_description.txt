A single-page network mode controller using Shizuku. Configure the target SIM, Quick Settings tile cycle and highlighted states, automatic shade collapse, and up to four launcher shortcuts at the bottom of the home page.

Supports preferred 5G/4G/3G and 5G/4G/2G Only modes where supported. Xiaomi and Android telephony state is verified after each change. Shizuku authorization is required. This build has no Root execution, external broadcast automation or guide pages.
